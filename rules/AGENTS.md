# AGY Studio Side Panel Rule

When working in a session that launches or coordinates multiple agents — including `invoke_subagent`, `swarm`, Claude Code (`claude`), OpenAI Codex CLI (`codex`), GitHub Copilot CLI (`copilot`), OpenCode (`opencode`), or DeepSeek CLI (`deepseek` / `dsh`), or when the user asks to watch running agents — include a single clickable sidecar link once per conversation (do not repeat on every turn once already offered):

[AGY Studio](sidecar://agy-studio/office/)
